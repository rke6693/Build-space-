# The Connected Line: Industry 4.0 micro course

A self-contained, single-file HTML micro course on Industry 4.0 for packaging and manufacturing. Open `index.html` in any modern browser; it needs no build step or server. Fonts load from Google Fonts when online and fall back to system fonts offline.

## What's inside

- **9 stations, 24 lessons, about 3 hours.** Topics run from foundations through architecture (ISA-95, UNS, RAMI 4.0, PackML), connectivity (IO-Link, OPC UA, MQTT/Sparkplug, edge vs cloud), performance (OEE, V-curve line design, SPC), digital twins and virtual commissioning, predictive maintenance and vision inspection, serialization and EPCIS 2.0, robots and Industry 5.0, and OT security and the maturity roadmap.
- **24 hands-on labs**, including a PackML state machine with live PackTags, an OEE calculator, an 8-hour packaging-line simulator (flat line vs V-curve), an SPC chart with Western Electric rules, a reject-timing virtual commissioning test, a P-F curve explorer, a vision threshold trade-off, a GS1 element string and Digital Link decoder, and an investment capstone.
- **Station checks** (4 questions each), a **final assessment** (20 questions drawn from every station, pass mark 80%), a **certificate** shown on screen, and a searchable **glossary** of 64 terms.

Progress is saved in the browser's `localStorage`, so it stays on that device and browser only.

When the page runs as a claude.ai Artifact, each lesson also shows an **Ask the tutor** panel backed by Claude. In a plain browser that panel stays hidden.
